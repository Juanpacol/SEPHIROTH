# Example studies

The landing page's feature grid shows `pathology.webp` in the "See" cell, and the imaging demo uses `xray`, `ct-brain`, `mri-brain` and `ultrasound`. They are also what `platform/api/static/imaging-demo/` bundles. (The other example studies that used to cycle there were removed on 2026-10-22: the cell now shows one still study.)
