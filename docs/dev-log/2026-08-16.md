# 2026-08-16

## Session 1 — Phase 0: SDD foundation, contracts, tool-authorization hotfix

**Goal**

Land Phase 0: make `src/sephiroth` importable everywhere, install the spec/doc
system, pin current behaviour with characterization tests, and close the tool
authorization hole.

**Did**

- Audited the repository against the transformation plan and produced a
  file-by-file migration map. Two of eight requirements were already met.
- Wrote `SPEC-000` (spec template and lifecycle) and
  `docs/00-migration-charter.md` (frozen contracts, shim rules, phase order).
- Built `src/sephiroth/contracts/` — 23 Pydantic models, leaf package, plus
  `scripts/export_contracts.py` and a CI-enforced JSON Schema drift gate.
- Wrote `tests/test_sse_contract.py` (12 assertions on the wire contract) and
  `tests/test_prompt_contract.py` (the script-key guard).
- **Closed the tool authorization hole**: `MCPRegistry.scoped_executor()`.
  Rolled out permissive-first, confirmed zero denials across a full eval run and
  the whole suite, then enforced.
- Made the project pip-installable (`[build-system]` + explicit src layout) and
  wired `pip install -e .` into CI and the Dockerfile.
- Wrote `scripts/docs_check.py` (6 gates) and a `docs` CI job.
- Deleted `docs/INTEGRATION_GUIDE.md` and the vestigial `AgentState` dataclass.
- Wrote the project/research/security docs, `ADR-001`–`ADR-010`, the
  traceability matrix, `D1`, and `SPEC-001` (the Phase 1 gate).

**Decisions**

- **LangGraph will be removed** (`ADR-001`), reversing the transformation plan's
  assumption. It compiles without a checkpointer and its fan-out requires
  enumerating destinations at compile time — which a dynamic planner cannot
  satisfy. Executed in Phase 3b, after parity is proven.
- **Editable install, not a `pythonpath` entry.** Extending `pythonpath` would
  serve pytest but not uvicorn, `python -m`, or Docker — a silent divergence
  between CI and production.
- **Tool authorization fixed in Phase 0, out of order.** Clinical text is
  untrusted input reaching a model whose output selects tool calls. Waiting two
  phases was not defensible.
- **Specs live in `docs/specs/`, not beside architecture prose.** Frozen
  normative documents and living descriptive ones rot each other.
- **Span attributes are an allow-list, not a deny-list.** A deny-list fails open,
  and in this domain the next unlisted field is patient data.

**Tried and rejected**

- Adding `"src"` to `pythonpath` — simplest, but covers only pytest.
- Putting the package at repo root as `sephiroth/` — zero config, consistent with
  `intelligence/` and `data/`, but the plan fixed `src/sephiroth/`.
- Salvaging `docs/INTEGRATION_GUIDE.md` — almost every code sample referenced
  something that does not exist. Rewriting from the code was faster than
  correcting it.
- Writing all ten ADRs before deciding whether the decisions were real. Held off
  on `ADR-001` until the audit confirmed the checkpointer was absent — the fact
  that turned the decision from preference into argument.

**Problems**

- `ruff format --check` failed on nine of my own files; `main` was clean, so the
  debt was mine. Fixed and re-verified the suite afterwards.
- The `/consult/stream` endpoint persists via `SessionLocal()` directly rather
  than the injectable dependency, so `test_sse_contract.py` has to patch the
  module attribute to test the `persisted` event.
- Docker was not running for the first verification pass; the smoke test was
  deferred and then run properly.

**Results**

- 260 → **359 tests**, all green. Coverage **88.46% → 91.05%**.
- Eval gate: PASS on all six metrics, unchanged.
- Docker: image builds, migrations run, `/health` healthy in 4s,
  `scripts/smoke_test.sh` PASSED. Authorization enforcement verified **inside the
  running container**, not only in tests.
- Bandit HIGH/HIGH: 0. pip-audit: no known vulnerabilities.
