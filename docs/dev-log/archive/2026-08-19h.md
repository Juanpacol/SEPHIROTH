# 2026-08-19 (session 8)

## Session — Phase 5, Part 3: relocate risk_engine/citation_guard/explainability

**Goal**

Third of 5 planned cycles closing the remaining SEPHIROTH gaps. Pure
strangler-fig relocation: `intelligence/agents/{risk_engine,citation_guard,
explainability}.py` move byte-for-byte into `src/sephiroth/`, the old
paths become shims. No behavior change, no new spec — the migration
charter's shim schedule already named this move for Phase 5.

**Did**

- Grepped every call site of the 3 modules first — only 2 public names per
  module used externally (`assess_patient_risk`/`assess_risk_level`,
  `audit`/`sanitize`/`CitationReport`, `build_explanation`).
- Moved each file verbatim: `risk_engine.py` → `src/sephiroth/safety/risk.py`,
  `citation_guard.py` → `src/sephiroth/verification/citation_guard.py`
  (kept as its own module, not merged into `claims.py`/`evidence.py` — it
  audits citation *labels*, a distinct job from claim-content
  verification), `explainability.py` → `src/sephiroth/telemetry/explain.py`
  (kept as the same `(agents, tool_calls, citation_report)` function, not
  reimplemented as an `ExecutionTrace` projection — that redesign stays
  out of scope this cycle).
- Rewrote the 3 old paths as pure re-export shims per
  `docs/00-migration-charter.md` rule 1 (no logic, no conditionals).
- Retargeted `platform/api/routers/{patients,dashboard,agents}.py` and
  `intelligence/evaluation/metrics.py` to import from the new paths
  directly.
- Promoted `src/sephiroth/runtime/executor.py`'s deferred, function-local
  `citation_guard`/`explainability` imports to normal module-level imports
  — the cross-package hazard that justified deferring them (importing
  `intelligence.agents` at module scope) is gone now that both live under
  `src/sephiroth/`.
- Added `tests/test_shim_identity_relocation.py` (charter rule 2: a shim
  must re-export the same object, not a copy) and a coverage `omit` entry
  for the 3 shim paths (charter rule 4).
- Updated the charter's shim schedule table, `project-state.yaml`
  (0.8.0), `CLAUDE.md` (decisions #6/#9/#10, folder table).

**Decisions**

- **`citation_guard` stays its own module** — its regex/token-matching
  provenance audit is a different job from `sephiroth.verification`'s
  claim-content verification; merging them would blur two distinct
  concerns for a relocation that's supposed to be behavior-neutral.
- **`explainability`'s `ExecutionTrace`-projection redesign deferred** —
  the plan flagged this as a "nice to have," not required; doing it now
  would turn a zero-risk relocation into a real redesign with its own
  test surface. Left as a documented future option, not built.

- Nothing — this cycle had no false starts; the relocation was
  byte-for-byte by design, so there was nothing to get wrong beyond import
  paths, which `ruff check --fix` caught immediately (import ordering).

  and `bandit` all passed on the first run after the moves.
