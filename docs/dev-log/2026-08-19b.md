## Session — DEBT-009: remove `intelligence/mcp/registry.py` shim

**Goal**

Close `DEBT-009`, opened at the end of the Phase 3 session: the migration
charter scheduled deleting `intelligence/mcp/registry.py` (the Phase 2 shim
over `sephiroth.tools`) in Phase 3, but that phase's approved scope was Agent
Runtime + `DEBT-008` and didn't include it. Isolated, mechanical cleanup
before starting real Phase 4 work, same pattern as `DEBT-008`.

**Did**

- Retargeted every call site importing `get_registry`/`MCPRegistry` from
  `intelligence.mcp`/`intelligence.mcp.registry` onto
  `sephiroth.tools.get_tool_runtime`/`ToolRuntime` directly:
  `platform/api/routers/{medical,rag,patients}.py`,
  `tests/{test_mcp,test_tool_authorization}.py`,
  `examples/{tools_example,imaging_example}.py`.
- Deleted `intelligence/mcp/registry.py` and `tests/test_mcp_shims.py`.
- Simplified `intelligence/mcp/__init__.py`: removed the PEP 562
  `__getattr__` lazy-resolution trick added in Phase 2 — with no call site
  requesting `MCPRegistry`/`get_registry` from this package anymore, the
  circular-import hazard it worked around no longer exists.
- `pyproject.toml`: removed `intelligence/mcp/registry.py` from
  `coverage.run.omit`.
- `docs/specs/SPEC-002-tool-runtime.md` → v1.2.0: retired the two acceptance
  criteria that verified the shim's identity and the legacy tests passing
  unmodified against it (same "no literal `AC-\d{3}-\d{2}` token in the
  retirement note" technique used for `SPEC-001`'s `DEBT-008` correction, to
  avoid re-triggering `docs_check.py`'s regex).
- `docs/project-state.yaml`: removed the `intelligence/mcp/registry.py`
  component entry, `DEBT-009` → resolved, `src/sephiroth/tools`'s test list
  updated.

**Decisions**

- **No merge of `tests/test_mcp.py` into `tests/test_tool_runtime.py`.**
  Both exercise the same underlying `ToolRuntime`, but from different angles
  (`test_mcp.py` is characterization/offline-tool behavior, `test_tool_runtime.py`
  is the Phase 2 spec's unit tests for timeout/tags). Merging them wasn't part
  of this cleanup's scope and would have mixed an unrelated refactor into a
  mechanical shim removal.

**Tried and rejected**

- Nothing — followed the approved plan directly.
