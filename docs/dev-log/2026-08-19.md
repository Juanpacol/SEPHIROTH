**Decisions**

- **`RunState`/`ToolCall`/`AgentResult` not adopted as the executor's internal
  state** (SPEC-003 §10, NG-2). Those Phase 0 contracts are strict
  (`extra="forbid"`) and `ToolCall`'s fields don't match the frozen wire shape
  — adopting them now would mean building instances only to immediately
  flatten them back for the wire, with no consumer of their extra fields yet.
  Deferred to the phase that actually accumulates evidence/claims/safety data.
- **LangGraph removed in this phase, not split into 3a/3b.** Already decided
  during planning (see 2026-08-16 approved-plan discussion): git provides the
  real rollback; keeping a second, dead implementation in the tree "just in
  case" is exactly the complexity-without-benefit `docs/00-project/scope.md`
  warns against. The three frozen parity test files passing unmodified serve
  as the parity proof instead of a dedicated comparison harness.
- **No dynamic capability-matching router this phase** (NG-1). `router.py` is
  a direct dictionary lookup; real capability matching is a later phase's
  addition, once there's more than one agent per capability to choose between.

**Tried and rejected**

- Nothing beyond what's listed in Problems — followed the approved plan
  directly; the complications below were bugs surfaced during implementation,
  not design choices reconsidered afterward.

**Problems**

- **Circular import, same shape as Phase 2's.** `sephiroth.runtime.executor`
  needs `intelligence.agents.citation_guard`/`explainability`, while
  `intelligence/agents/__init__.py` now imports from `sephiroth.runtime` at
  module level — a module-level import in `executor.py` would cycle. Fixed by
  deferring those two imports to inside `run_consultation`/`stream_consultation`'s
  function bodies, same pattern as the Phase 2 `intelligence.mcp` fix.
- **`tests/test_prompt_contract.py` broke on the class→instance move.** Five
  assertions did `agent_cls.role_prompt`/`agent_cls.name` as class attributes,
  which no longer exist since `Agent.name` is an instance `@property`.
  Rewrote the affected tests to read `sephiroth.runtime.registry.AGENTS`
  directly for the ones that only inspect data (not run an agent).
- **A test I wrote myself was wrong before it ever ran.** An early draft of
  `test_agents_involved_is_alphabetically_sorted_regardless_of_completion_order`
  asserted against `run_consultation`'s return dict, which has no
  `agents_involved` key (only `stream_consultation`'s final event does) and
  whose `agent_outputs` dict follows declaration order, not alphabetical order
  — the assertion as written would have been false by construction. Caught it
  before running and rewrote it against `stream_consultation`'s `final` event.
- **`docs_check.py`'s AC-coverage regex re-matched a retired criterion's own
  retirement note.** Deleting `tests/test_llm_shims.py` (DEBT-008) removed the
  test that verified `SPEC-001`'s eighth acceptance criterion, but the note
  explaining the retirement still contained the literal `AC-001-08` token,
  which the gate's regex matched as if it were still a live, testable
  criterion. Reworded the note to describe the retirement in prose without
  the hyphenated pattern — same fix shape as Phase 1's SPEC-001 correction.
