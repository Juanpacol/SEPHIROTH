# Synthetic patients — Synthea Coherent Data Set

**Source:** [Synthea Coherent Data Set](https://registry.opendata.aws/synthea-coherent-data/) (MITRE), a public dataset of fully synthetic patient records, hosted at `s3://synthea-open-data/coherent/` (public, no AWS account needed).
**License:** CC BY 4.0 (dataset) / Apache 2.0 (the Synthea generator itself). 100% synthetic — no real patient data, no PHI, no privacy risk.

## What's committed vs. what's fetched on demand

- **`sample_patients.json`** (committed, ~36 KB): 12 real Synthea patients, already parsed into the exact shape `data/schemas.Patient`/`TimelineEvent` expects — picked for having clinically rich, varied histories (multiple chronic conditions, medications, and timeline events). Ready to use with zero setup.
- **`synthea_raw/`** (gitignored, ~6 MB when populated): the filtered CSV rows for the sample patients — regenerated by `fetch_synthea_sample.py`, not committed (Synthea's raw dataset files are large and easy to re-fetch; the parsed JSON above is the useful, small artifact).

## Regenerating

```bash
# 1. Download + filter a fresh sample (network required)
PYTHONPATH=. python3 real_data/patients/fetch_synthea_sample.py

# 2a. Insert into the Postgres database, alongside the deterministic
#     demo seed (P001/P002 — untouched, see platform/core/db.py)
PYTHONPATH=.:platform python3 real_data/patients/import_synthea.py --limit 25

# 2b. Or regenerate the committed sample_patients.json artifact:
PYTHONPATH=.:platform python3 -c "
import json, dataclasses, datetime
from real_data.patients.import_synthea import parse_patients
from pathlib import Path
patients = parse_patients(Path('real_data/patients/synthea_raw'), as_of=datetime.date.today())
patients.sort(key=lambda p: len(p.timeline), reverse=True)
json.dump([dataclasses.asdict(p) for p in patients[:12]], open('real_data/patients/sample_patients.json', 'w'), indent=2)
"
```

Never runs in CI/tests — `tests/test_real_data_patients.py` exercises the parsing logic (`parse_patients`) against tiny inline fixture CSVs instead.

## Why not just download the full pre-generated zip?

The MITRE-hosted "1k patients" package on `synthea.mitre.org/downloads` is a JS-rendered page without stable direct download links, and the full Coherent dataset zip is ~9 GB. `fetch_synthea_sample.py` instead reads directly from the underlying public S3 bucket, downloading the small tables (`patients.csv`, `conditions.csv`, `allergies.csv`) whole and **streaming + filtering** the large ones (`medications.csv` ~90 MB, `observations.csv` ~240 MB) line-by-line so nothing large ever touches disk.
